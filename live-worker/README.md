# 현단아의 뉴뀨? — 참가자 15명용 실시간 웹화면

진행자는 기존 `http://127.0.0.1:8765/studio`에서 문제를 조작합니다. 참가자는 **공개 HTTPS 주소의 /obs**로 접속하여 오프닝 대기, 제목, 합성 문제, 정답 공개, 다음 문제 준비중 영상, 종료 화면을 **보기만** 합니다.

## Cloudflare Worker 배포 (한 번만)
1. Cloudflare 계정에서 Workers를 이용할 수 있어야 합니다.
2. 이 `live-worker` 폴더에서 `npx wrangler login`을 실행한 뒤 `npx wrangler secret put PUBLISH_TOKEN`으로 16자 이상 무작위 비밀키를 등록합니다. 개인키는 GitHub에 올리지 마세요.
3. `npx wrangler deploy`를 실행하고 출력된 `https://...workers.dev` 주소를 기록합니다.
4. **프로그램 v1.8.1 이상** 방송 진행실의 '참가자 실시간 화면 공유 설정'에서 Workers 주소와 2번의 비밀키를 입력하고 **중계 연결**을 누릅니다.
5. **방송 화면 이미지·MP4 동기화** 버튼을 눌러 기존 로컬 방송 이미지를 Cloudflare로 옮깁니다. 참가자 화면에서 기존 OBS 렌더러 디자인을 사용합니다.
6. **참가자 주소 복사** 버튼으로 `https://...workers.dev/obs` 링크를 참가자에게 전송합니다. 참가자는 프로그램 설치가 필요 없습니다.

## 보안·운영
- 외부 공개 주소는 Cloudflare HTTPS 링크 하나입니다. 로컬 `127.0.0.1:8765`와 8765 포트는 외부에 공개하지 않습니다.
- 진행실에서 공개한 합성 이미지와 이미 공개한 원본·이름·출처만 Worker가 보관합니다. 관리자 버튼과 문제 관리실은 외부에 공개하지 않습니다.
- 비밀키는 진행자 브라우저 로컬 저장소에만 저장됩니다. 참가자에게 알려주지 마세요.
- Cloudflare Worker 주소는 링크를 아는 누구나 볼 수 있습니다. 초대자만 입장시키는 추가 인증은 아직 구현되지 않았습니다.
- 중계가 끊기면 마지막 화면이 남을 수 있습니다. 실제 방송 전 연결·화면 전환·15명 동시 접속을 테스트해야 합니다.
- Cloudflare 무료 요금제에는 요청량 및 저장소 사용량 제한이 있습니다.
