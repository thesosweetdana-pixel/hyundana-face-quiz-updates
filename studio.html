연예인 원본 사진 보관함

완료·삭제된 문제와 별도로 원본 사진·이름·출처 보관 · 동일 인물 여러 장 가능
체크한 사진을 기존 문제와 분리해 이 PC의 사진 보관함에 저장합니다.

사진 보관함에 직접 추가하거나, 제작실에서 문제 저장 시 자동으로 쌓입니다. 원본을 새 문제의 A·B·C에 불러와도 다른 문제의 정렬 정보는 바뀌지 않습니다.

사진 보관함을 불러오는 중...
0 / 3장 선택

사진 카드의 「3명 선택」을 누른 순서대로 A → B → C에 배치됩니다. 검색을 바꿔도 선택은 유지돼요. 출처·이름도 함께 들어가며 원본과 이전 문제는 그대로 보관됩니다.

「보관함 삭제」는 기존 문제를 보존합니다. 「전체 삭제」는 해당 원본을 사용하는 문제의 사진·이름·출처를 제거하고 문제를 제작 중으로 되돌립니다. 삭제 전 전체 백업을 권장합니다. 반대로 문제를 삭제해도 보관함 사진은 남습니다. 문제 및 사진 전체 백업은 문제 관리실의 「전체 문제 백업 JSON」에서 받을 수 있어요. 이 기기에 저장되므로 다른 PC로 옮기거나 브라우저 데이터를 지우기 전에 꼭 백업하세요.

문제 관리실

문제를 여러 개 보관하고 순서를 정리하세요. 정답 정보는 진행자 화면에서만 확인합니다.
저장된 문제를 불러오고 있어요.
저장 위치: 가능하면 현재 브라우저의 로컬 데이터베이스(IndexedDB). 저장소가 차단되면 이번 실행 중에만 임시 보관됩니다. 브라우저 데이터를 삭제하거나 다른 PC로 이동하면 사라질 수 있으니 전체 문제 백업 JSON을 내려받아 보관하세요. “진행 준비”는 문제 내용 점검 상태입니다. OBS 연동은 로컬 서버를 실행하고 방송 진행실에서 확인하세요.

참가자용 중계 서버가 아직 연결되지 않았어요.

주의: 진행실 전체를 방송에 캡처하면 정답이 노출됩니다. 참가자에게는 Cloudflare 보기 전용 링크만 공유하세요.
원본 사진과 합성 이미지는 사전 준비하고, 재생 중에는 사진끼리 페이드 전환합니다. 완료된 문제는 진행 대기 목록에서 제외되고 오른쪽 목록으로 이동합니다.
